# Database Rules

## ORM
Use **SQLAlchemy 2.x async** exclusively. No raw SQL except in Alembic migrations or performance-critical aggregations.

## Repository Pattern
- All SQLAlchemy calls must live in `app/repositories/`
- One file per entity: `order_repository.py`, `shipment_repository.py`, `product_repository.py`, etc.
- Services import repositories — never import `AsyncSession` directly in services or routers

## Database Session
- Single async session factory in `app/core/database.py`
- Inject via FastAPI dependency: `session: AsyncSession = Depends(get_db_session)`
- Never create sessions manually outside the dependency

## Model Conventions (`app/models/`)
- All models use `snake_case` column names
- Primary keys: `id: Mapped[str] = mapped_column(primary_key=True)` — Order uses `ORD-YYYYMMDD-XXXXX` format, others use `str(uuid4())`
- Timestamps: `created_at` and `updated_at` managed by SQLAlchemy `server_default` / `onupdate` — do NOT set manually
- Enum values: Python `enum.Enum` with string values matching the DB enum type
- Soft deletes: use `deleted_at: Mapped[datetime | None]` — do NOT hard-delete Orders or Customers

## Repository Query Rules
```python
# app/repositories/order_repository.py
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select
from sqlalchemy.orm import selectinload
from app.models.order import Order

class OrderRepository:
    def __init__(self, session: AsyncSession):
        self.session = session

    async def get_by_id(self, order_id: str) -> Order | None:
        result = await self.session.execute(
            select(Order)
            .where(Order.id == order_id)
            .options(selectinload(Order.items))
        )
        return result.scalar_one_or_none()
```

- Pagination: always use `.offset(skip).limit(min(limit, 100))`
- Load relationships explicitly with `selectinload()` or `joinedload()` — never rely on lazy loading in async context (raises `MissingGreenlet`)
- Wrap multi-step operations in `async with session.begin()`

## Migration Rules (Alembic)
- Never edit an existing migration file
- Generate: `alembic revision --autogenerate -m "add_tracking_events_table"`
- Migration names: `snake_case` describing what changed
- Always review autogenerated migration before applying
- Apply: `alembic upgrade head`
- Rollback: `alembic downgrade -1`

## Seeding
- Seed file: `app/db/seed.py`
- Run with: `python -m app.db.seed`
- Seed data uses realistic but fake data (no real PII)
- Order seed data uses valid `ORD-YYYYMMDD-XXXXX` format

## Indexes
Declare indexes directly on models:
```python
from sqlalchemy import Index

class Order(Base):
    __table_args__ = (
        Index("ix_orders_customer_id", "customer_id"),
        Index("ix_orders_status", "status"),
    )
```
Required indexes:
- `orders.customer_id` — frequent filter
- `orders.status` — frequent filter
- `shipments.tracking_number` — lookup
- `tracking_events.shipment_id` — frequent join
